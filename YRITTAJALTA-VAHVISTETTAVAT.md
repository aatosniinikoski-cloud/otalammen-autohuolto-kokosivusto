- Vahvistettu puhelinnumero.
- Tarkka käyntiosoite ja karttalinkki.
- Aukioloajat.
- Y-tunnus / juridiset yritystiedot.

- Oma vastaanottava API / serverless-endpoint ja tarvittaessa sen palvelinpuolinen GoHighLevel-yhteys.
- Verkkotunnus ja erillinen hyväksyntä julkaisemiselle.
